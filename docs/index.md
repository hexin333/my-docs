## 学无止境

本项目使用 `VitePress` 搭建，记录一些前后端以及AI相关的知识。克隆项目以后，通过以下命令可以本地运行该项目（node以及npm的版本号参考 `package.json` 文件中的 `engines` 字段）。

```sh
npm install
npm run dev:docs
```
