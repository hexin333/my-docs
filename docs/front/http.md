# HTTP相关

## http和https的区别

::: details 详情
| 维度 | HTTP | HTTPS |
| ---------- | ---------------- | ------------- |
| **全称** | HyperText Transfer Protocol | HyperText Transfer Protocol **Secure** |
| **安全性** | **明文传输**，数据不加密，易被窃听、篡改、劫持 | **加密传输**，通过 TLS/SSL 对通信内容加密，防止中间人攻击 |
| **默认端口** | `80` | `443` |
| **证书要求** | 不需要 | **需要 SSL/TLS 证书**（服务器需向 CA 机构申请并配置，TLS是SSL的升级版） |
| **连接建立过程** | TCP 三次握手后直接传数据 | TCP 握手 → **TLS 握手**（交换密钥、验证证书）→ 加密传输 |
| **URL 前缀** | `http://` | `https://` |
| **性能** | 无加密开销，理论上略快 | 有 TLS 握手和加解密开销；但现代浏览器中 **HTTP/2 通常仅支持 HTTPS**，多路复用后实际体验可能更快 |
| **SEO/信任** | 浏览器标记"不安全"，搜索引擎降权 | 浏览器显示锁图标，搜索引擎优先收录 |
| **成本** | 无证书成本 | 过去证书昂贵，现在 Let's Encrypt 等提供免费证书，主要成本是配置维护 |

:::

## https加密过程，什么时候是非对称加密，什么时候是对称加密

::: details 详情

- 两个阶段的分工
  | 阶段 | 加密方式 | 作用 | 具体行为 |
  | ------------ | ----- | --------------- | ------------- |
  | **TLS 握手阶段** | **非对称加密** | 身份验证 + 安全交换对称密钥 | 服务器持私钥，客户端用服务器公钥加密「预主密钥」发送 |
  | **数据传输阶段** | **对称加密** | 实际 HTTP 报文加密通信 | 双方用握手阶段协商出的**会话密钥**（对称）加解密所有请求/响应 |

- 为什么这样设计？
  | 加密方式 | 优点 | 缺点 | 适用场景 |
  | ---------- | ------------ | ----------------- | ---------------- |
  | **非对称加密**（RSA/ECDHE） | 无需共享私钥，天然防窃听 | 计算极慢，比对称加密慢 **100~1000 倍** | 仅用于握手阶段的短数据交换 |
  | **对称加密**（AES） | 计算极快，适合流式大数据 | 双方必须持有相同密钥，密钥分发困难 | 用于后续所有 HTTP 数据传输 |

:::

## http请求常见的响应码

::: details 详情

- 2xx 成功（Success）
  | 状态码 | 含义 | 场景 |
  | ------- | ---------- | -------------- |
  | **200** | OK | 请求成功，最常见的正常响应 |

- 3xx 重定向（Redirection）
  | 状态码 | 含义 | 场景 |
  | ------- | ----------------- | ------------------ |
  | **301** | Moved Permanently | 资源永久迁移到新 URL，搜索引擎会更新索引（如换域名） |
  | **302** | Found | 临时重定向，客户端应继续用原 URL 请求（如未登录跳转登录页） |
  | **304** | Not Modified | 协商缓存命中，资源未变更，浏览器直接用本地缓存 |

- 4xx 客户端错误（Client Error）
  | 状态码 | 含义 | 场景 |
  | ------- | ---------------- | ------------------- |
  | **400** | Bad Request | 请求参数格式错误或缺少必填字段 |
  | **401** | Unauthorized | 未认证/未登录（缺少或无效的 Token） |
  | **403** | Forbidden | 已登录但无权限访问（如普通用户访问 admin 接口） |
  | **404** | Not Found | 资源不存在（URL 错误或资源已被删除） |
  | **405** | Method Not Allowed | HTTP 方法不被允许（如用 POST 访问只支持 GET 的接口） |

- 5xx 服务器错误（Server Error）
  | 状态码 | 含义 | 场景 |
  | ------- | --------------- | ------------------ |
  | **500** | Internal Server Error | 服务器内部未知错误（代码抛异常、数据库连接失败等） |
  | **502** | Bad Gateway | 网关/代理从上游服务器收到无效响应（如 Nginx → Node 服务挂了） |
  | **503** | Service Unavailable | 服务器过载或维护中（如秒杀时拒绝服务、停机部署） |
  | **504** | Gateway Timeout | 网关/代理等待上游响应超时（如后端处理太慢，Nginx 默认 60s 超时） |

:::
